## The problem

General Arrangement (GA) drawings involve the same engineering steps again and again: collecting requirements, entering parameters, configuring models, preparing views, applying drawing information and repeating similar documentation. Done by hand, this eats engineering time and invites inconsistency.

## The solution

I built a SolidWorks automation workflow driven by **structured requirement data** and a custom **automation form**. Instead of repeating the same sequence manually, the engineer enters the required inputs once through a structured interface, and the workflow handles the repetitive CAD and drawing operations.

## Workflow

**Before — manual**

Requirement → Engineer → CAD → CAD → CAD → Drawing → Review → Changes → Drawing

**After — automated**

Requirement → Input form → Automated CAD operations → GA drawing → Review

## Technology

- SolidWorks
- SolidWorks API / VBA-based automation
- Structured engineering inputs
- Custom automation forms
- Engineering drawing workflows

## Impact

The workflow targets roughly a **60–80% reduction in repetitive GA drawing effort**, depending on the drawing and configuration. The bigger goal wasn't one faster drawing. It was a repeatable engineering workflow that scales across similar design requirements.

## Engineering principle

> Automate the repetitive. Standardise the predictable. Keep engineering judgment where it matters.
